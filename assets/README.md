# assets/

Ana sayfadaki kart fotoğrafları buraya gelir:

```
assets/sila.jpg     ← Sıla
assets/okan.jpg     ← Okan
```

`.jpg` şart değil — `.jpeg`, `.png`, `.webp` de çalışır.

Buraya koymazsan ana sayfa laboratuvarınkileri kullanır
(`anatomi/assets/slay.*` ve `anatomi/assets/0k4n.*`), yani tek bir yere
koyman yeterli. Hiçbiri yoksa kartta "sürükle bırak" yer tutucusu görünür,
site bozulmaz.
